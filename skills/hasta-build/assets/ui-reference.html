ခေတ်မီသော Tags များ

UI Architect အတွက် အဓိက စည်းမျဉ်း — screen တစ်ခုလျှင် landmark တစ်ခု၊ class-soup ဖျောက်ပစ်၊ native tag ကို ပထမဦးစားပေး။ Flutter တွင် semantic tag ၏ အနက်ကို Semantics widget ဖြင့် တွဲသုံး၍ TalkBack/VoiceOver အတူတူ ရအောင် လုပ်သည်။

Modern attributes (မဖြစ်မနေ)

  • ✓
    popover / popoverhint — reaction bar နှင့် tooltip ကို JS ရိုးရိုးမဟုတ်ဘတ် native popover ဖြင့်
  • ✓
    inert — dialog ပွင့်စဉ် backlog ကို focus မရစေရန်
  • ✓
    aria-live="polite" — message status (pending → sent → read) ပြောင်းလဲမှု ကြားသိစေရန်
  • ✓
    enterkeyhint="send" — chat input bar တွင်
  • ✓
    loading="lazy" decoding="async" — feed media အားလုံးတွင်
  • ✓
    contenteditable="false" — forwarded content ကို edit မလုပ်ရန်
  • ✓
    role="status" role="img" aria-label — icon-only button တိုင်း
